# Recurrent Neural Networks for Disease Progression Prediction

## Reframed Project Scope
This project began as a proposal focused on recurrent neural networks for longitudinal disease progression prediction. Because the Pima Indians Diabetes dataset is a static tabular dataset rather than a true time series of repeated patient visits, the final project is reframed as an honest comparison of static diabetes prediction models.

## Final Working Title
**Recurrent Neural Networks for Disease Progression Prediction: A Reframed Static Diabetes Prediction Comparison**

## Core Question
Can an LSTM-inspired deep learning approach outperform strong classical machine learning models such as Random Forest and Gradient Boosting on the Pima diabetes dataset?

## Models
- Random Forest
- Gradient Boosting
- LSTM-based neural model adapted for static/tabular input

## Dataset
- Pima Diabetes dataset
- Target column: `Class`
